# 💙 Sistema de Recordatorios para Astrid

Un regalo especial de San Valentín: una página web personalizada con recordatorios y notificaciones.

## 🎁 ¿Qué es esto?

Una aplicación web con temática de Stitch que permite:
- ✅ Crear recordatorios con fecha y hora
- 🎤 Dictar recordatorios por voz
- 🔔 Recibir notificaciones en el momento indicado
- 💕 Recibir mensajes especiales sorpresa
- 📱 Usar desde cualquier dispositivo (móvil, tablet, PC)

## 🚀 Inicio Rápido

1. Descarga el archivo `recordatorios-astrid.html`
2. Ábrelo en tu navegador
3. Contraseña: `Astrid2025`
4. ¡Disfruta!
